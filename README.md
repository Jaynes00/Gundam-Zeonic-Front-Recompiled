# Mobile Suit Gundam: Zeonic Front — Recompiled

An unofficial native Windows PC port of **Mobile Suit Gundam: Zeonic Front (2001)**, originally released for the PlayStation 2.

This fan project aims to preserve the original gameplay experience while bringing Zeonic Front to modern PCs with improved performance, widescreen support, and quality-of-life enhancements.

## Features

- Native Windows PC gameplay without requiring a PS2 emulator.
- 60 FPS support.
- Widescreen 16:9 and original 4:3 display options.
- Adjustable resolution and draw distance.
- Original campaign, including Round 1 and Round 2.
- Simulation Programs and original mission progression.
- Controller support.
- Original game assets imported from your own PS2 ISO.

## Installation

1. Download the latest release from the GitHub **Releases** section.
2. Extract the archive to a folder of your choice.
3. Run the included launcher.
4. Select your legally obtained *Zeonic Front* PS2 ISO when prompted.
5. Press F10 configure your graphics and controls, then launch the game.

**A user-supplied copy of the original game is required.** No original game ISO is included with this project.

## Project Status

The main PC port is playable, with the campaign and Simulation Programs implemented.

Some minor graphical and gameplay discrepancies may remain as development and community testing continue.
